# myJobLauncher 操作ガイド

バージョン 1.0（2026/09/30）

登録しておいたコマンドを画面のボタンから実行できる、社内向けの汎用ランチャーアプリです。
定型作業（バッチ処理・ファイル操作など）をボタン化し、コマンドを覚えていなくても安全に実行できるようにします。

## できること

- 「ホーム」タブで、お知らせメッセージ・ホーム本文をMarkdownとして表示（緊急のお知らせは起動時にポップアップ通知）
- 登録済みジョブをボタンひとつで実行（同期／非同期）、実行結果・出力ログの確認
- ジョブは「定型」「非定型」の種別を持ち、非定型ジョブは業務記録プラグイン（ストップウォッチ）で作業時間を計測して実行履歴へ記録
- ジョブに「Tier」（業務の階層）を設定して分類できる
- ジョブの複数選択（一覧左端のチェックボックス）による、すぐに実行／時刻を指定して実行
- 実行中・実行予定・完了などをステータス絵文字と青文字（実行中）で一覧表示
- 過去の実行実績から「日次／週次／月次／その他」を自動判定した一覧表示（列ごとにソート可能）
- ジョブごとに業務マニュアル（手順書のURL・フォルダ・ファイル）をワンクリックで開ける
- ジョブ単位の実行履歴（月別・日別集計）
- よく使うツール・よく使うリンクの登録・起動
- Obsidian Vault（または任意のフォルダ）へ、個人単位・日付単位で「本日の作業実績／明日の作業予定／TODO／相談事項／連絡事項」を出力する日報機能
- 日付をまたいで持ち越せる個人用TODOリスト（完了時にObsidianノートまたはExcelファイルへ自動記録）

## 画面構成

左側のメニューから画面を切り替えます。

| メニュー | できること |
| --- | --- |
| ホーム | お知らせメッセージ・ホーム本文をMarkdownで閲覧（起動時の既定画面） |
| 実行 | ジョブの一覧から選んで実行・停止、業務マニュアルを開く、ジョブごとの実行履歴を見る |
| 設定 | ジョブの追加・編集・削除、タイムゾーン設定、ストレージ設定、APIキーの登録 |
| ログ | 実行ログの確認・コピー・クリア |
| ツール | よく使うツールの登録・起動 |
| リンク | よく使うURL・フォルダ・ファイルの登録・起動 |
| 日報 | Obsidian Vault（任意のフォルダ）へ、個人・日付単位で作業実績/予定を出力 |
| ヘルプ | この操作ガイドの閲覧 |
| TIPS | 役立つ外部ドキュメント・参考URLの登録・閲覧 |

ジョブを実行すると自動的に「ログ」メニューへ切り替わり、出力を確認できます。

## ホーム

アプリ起動時に最初に表示される画面です。「お知らせメッセージ」と「よく使うサービス」（ホーム本文）をMarkdownとして閲覧できます。リンクはクリックするとブラウザで開き、マウスを乗せている間はその内容の直下にリンク先URLが表示されます。Mermaid図があれば「図をブラウザで表示」から確認できます。
お知らせは公開日時が来たものだけ表示され、通知期間が過ぎると自動的に表示されなくなります。
「緊急通知」に指定したお知らせは、公開日時が来るとアプリ起動時にポップアップ表示されます。
お知らせ・ホーム本文は「設定」タブから追加・編集できます。
各お知らせは見出しをクリックすると折りたたみ・展開でき、「全て折りたたむ」「全て展開する」で一括切り替えもできます。
表示エリア下端のハンドルをドラッグすると、お知らせの表示エリアの高さを調整できます（この高さはこのPCの設定として保存され、次回起動時にも引き継がれます）。

## 複数ジョブの実行

実行タブの一覧左端「選択」列のチェックボックスにチェックを入れると、複数のジョブを選択できます。
2件以上選択すると「すぐに実行」（並行実行）と「時刻を指定して実行」を選べます。
`{パラメータ名}` を含むジョブ、非定型ジョブは一括実行の対象外です（個別に実行してください）。

## ジョブの追加・編集

「設定」タブの「ジョブを追加」／ジョブ一覧の鉛筆アイコン、または実行タブのジョブ名を右クリック→「ジョブ情報の編集」から、画面操作だけで追加・編集・削除できます。
`{パラメータ名}` と書いた部分は、実行時に入力ダイアログで値を指定できます。

実行タブのジョブ名を右クリックすると、表示位置の変更（上下移動）・ジョブ情報の編集・業務マニュアルの編集・ジョブの無効化/有効化・ジョブの削除を選べます。無効化したジョブは実行できなくなります。

## 非定型業務の記録

種別を「非定型」にしたジョブは、コマンドを実行する代わりに業務記録プラグイン（ストップウォッチ）を起動し、作業時間を計測します。
「設定」タブの「識別子（ユーザー名）」欄に、業務記録プラグインへ渡す識別子（ユーザー名）を登録しておいてください。

1. 実行タブで非定型ジョブを選び「実行」を押すと、業務記録プラグインが開き計測が始まる（「設定」タブで登録した識別子・選んだジョブ名が自動入力され、コメント欄には固定で「ランチャー連携開始」が入力されます）
2. 作業が終わったら「完了として記録」を押すと、開始〜終了時刻が実行履歴へ記録される

## 日報の出力

「日報」タブで、Obsidian Vault（または任意のフォルダ）に「本日の作業実績」「明日の作業予定」「TODO」「相談事項」「連絡事項」をMarkdownとして出力できます。

1. 「出力先フォルダ」「個人名」、必要なら「タグの既定値（テンプレート）」（`{yymmdd}` で対象日の日付に自動展開）・「Excel出力先ファイル」（TODOの書き込み先に使う場合）を入力して「既定値を保存」を押す（次回以降は自動入力されます）
2. 対象日（既定は今日）を指定する
3. 「本日実施したジョブを取り込む」を押すと、その日に実行したジョブの実行履歴が「本日の作業実績」へ取り込まれる
4. 「明日の作業予定」を入力する
5. 「TODO」欄・「相談事項」欄・「連絡事項」欄を必要に応じて入力する（次項「TODOの管理」参照）
6. 「Obsidianへ出力」を押す

## TODOの管理

「日報」タブの「TODO」欄は、日付をまたいで持ち越せる個人用のTODOリストです。

1. 「TODOを追加」から件名・内容（Markdown）・期限・「書き込み先」（Obsidian／Excel）を入力して追加する
2. 「内容」欄は、記入テンプレート（タスク／課題／トラブル）を選ぶと見出し構成が自動で入力されます（入力済みの内容がある場合は上書きするか確認されます）。「プレビュー」ボタンで表示イメージを確認できます
   - テンプレート自体は歯車アイコンから追加・編集・削除できます
3. 一覧には件名（と期限）だけが表示されます。内容を確認・修正したいときは編集アイコンから開いてください
4. 完了したら✓（済にする）アイコンを押す。書き込み先に応じて、Obsidianなら`出力先フォルダ/個人名/TODO.md`へ、Excelなら「設定」で指定した`.xlsx`ファイルの`TODO`シートへ件名・内容・期限が記録され、完了扱いになります
   （Excelを書き込み先にする場合は、事前に「Excel出力先ファイル」を入力し「既定値を保存」しておいてください）
5. 完了したTODOは取り消し線付きで一覧に残ります（編集はできません。削除は可能）
6. 未完了のTODOはアプリを再起動しても残ります。日報を出力すると、その時点の全TODO（完了・未完了とも、件名のみ）が日報Markdownの「TODO」欄にも書き出されます

## タイムゾーン

実行履歴・日報・スケジュール実行の日付/時刻は、既定で日本時間（Asia/Tokyo）を基準にします。
「設定」タブの「タイムゾーン」欄から変更できます（スケジュール実行への反映にはアプリの再起動が必要です）。

## テーマ

「設定」タブの「テーマ」欄から画面の配色を切り替えられます（シンプルモダンのダーク／ライト／システム追従、モノトーン〈緑×黒〉）。保存すると即座に反映されます。
モノトーンでは、色付きの絵文字（✅❌等）の代わりに ○×△●◇ の記号でステータスを表示します。

## Tier（業務の階層）

「設定」タブの「Tier設定」で、Tier1〜8（全体共有）とTier9（個人専用、必須）の名称を登録できます。ジョブの追加・編集時に、登録したTierから1つを選べます（未設定も可）。実行タブの「Tier」列で確認でき、右上の「Tierで絞り込み」から特定のTierのジョブだけを表示できます。

## 困ったときは

- 実行ログとアプリ内部の動作ログは共通の書式で統一されており、アプリ画面（「ログ」タブ）のほか `logs/app-YYYYMMDD.log`（日付単位のファイル）にも保存されます。書式・日時形式・出力先は `config/log_format.toml` を作成・編集することでカスタマイズできます（詳しくは `README.md` を参照）
- 「ログ」タブは起動時に当日分のログをまとめて表示するため、アプリを起動する前に出力された分もさかのぼって確認できます。マウスでドラッグすれば複数行にまたがる範囲を選んでコピーできます
- 登録したAPIキーは、このPC・このWindowsユーザーでのみ復号できる形式で暗号化されます
- より詳しい設定ファイルの構造などは、リポジトリの `README.md` を参照してください
- 画面を開かずターミナルだけで「実行」「履歴確認」をしたい場合は `uv run mj --tui` も利用できます（設定等の編集はできません）
